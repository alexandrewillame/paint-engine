Paintings from a seed

Every random choice the engine makes (stroke texture, splatter, colour jitter) comes from a seed. In this demo a short composition script also takes the layout and colours from that seed, so a single integer reproduces the whole painting: same seed and style, same picture, at any size. The page starts on a random seed; the URL keeps it.

Seed Repaint with the same seed and style: same painting.

Avatars from user IDs

A painted placeholder per account, seeded with its numeric ID: nothing generated ahead of time, nothing stored.

Covers from post IDs

A header image per post, seeded with the post's ID.
